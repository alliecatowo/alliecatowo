# Projects

## Open-Source Products

### [lumen](https://github.com/alliecatowo/lumen)
- **Problem**: Existing general-purpose languages are not optimized for deterministic agent workflows.
- **What I Built**: A markdown-native, statically typed language direction in Rust with AI-native primitives.
- **Stack**: Rust, Cranelift.
- **Status**: Active.

### [minis-ai](https://github.com/alliecatowo/minis-ai)
- **Problem**: Team feedback loops are slow and AI personas often feel generic.
- **What I Built**: Mini teammate clones distilled from developer signal to simulate pre-review feedback.
- **Stack**: Python.
- **Status**: Active.

### [assistarr](https://github.com/alliecatowo/assistarr)
- **Problem**: Self-hosted media ecosystems are powerful but operationally fragmented.
- **What I Built**: An AI control layer for Jellyfin and the *arr stack via natural language workflows.
- **Stack**: TypeScript, Nuxt.
- **Status**: Active.

### [alliecode](https://github.com/alliecatowo/alliecode)
- **Problem**: AI coding CLIs are often tied to one provider or brittle UX.
- **What I Built**: A provider-agnostic coding CLI with strong terminal interaction patterns.
- **Stack**: Go.
- **Status**: Active.

### [anvil](https://github.com/alliecatowo/anvil)
- **Problem**: Traditional IDE workflows are not built for agent-native development loops.
- **What I Built**: A post-IDE macOS development environment experiment.
- **Stack**: Swift.
- **Status**: Active.
