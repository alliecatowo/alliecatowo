## 🏆 JupyterLite WebMCP

**Selected as one of 10 winners of the 2026 OpenAI WebMCP Challenge.**

[JupyterLite WebMCP](https://github.com/alliecatowo/jupyterlite-web-mcp) lets an agent work inside the notebook you already have open — the same unsaved cells, current selection, running kernel, outputs, and review state — through WebMCP, with changes happening visibly in place.

**[Repo](https://github.com/alliecatowo/jupyterlite-web-mcp)** · **[Live demo](https://jupyterlite-web-mcp.vercel.app/lab/index.html)** · **[Devpost](https://devpost.com/software/jupyterlite-webmcp)**

## Social systems

- **[Patches](https://github.com/alliecatowo/patches)** — terminal-native social media: chronological, open-source, no ranking algorithm, with a full TUI and responsive web client.

## Languages & runtimes

- **[Lumen](https://github.com/alliecatowo/lumen)** — a Markdown-native, statically typed language in Rust for deterministic agent workflows.
- **[Shoal](https://github.com/alliecatowo/shoal)** — a structured shell for humans and agents: typed values, content-addressed tool resolution, capability boundaries, and an MCP-native surface.
- **[puml](https://github.com/alliecatowo/puml)** — a native Rust PlantUML-compatible language/toolchain with no Java, including CLI, LSP, WASM, and SVG/PNG/PDF rendering.

## Developer tooling

- **[Glassy](https://github.com/alliecatowo/glassy)** — a minimal GPU-accelerated terminal emulator in Rust, built around low idle overhead and fast agent-heavy terminal workflows.
- **[Ticketmaster (`tm`)](https://github.com/alliecatowo/ticket-master)** — an interactive coding agent with a ticket-powered background crew: dispatch workers, inspect their work, review submissions, and keep shipping.

## How I Like to Build

- Deterministic systems over magical black boxes where reliability matters.
- Agent workflows should be inspectable, composable, and fast to iterate.
- Product feel matters as much as architecture quality.
- I build a lot of prototypes because the fastest way to understand an idea is usually to ship it.

## Work With Me
